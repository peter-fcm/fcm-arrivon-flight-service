== Overview
The Flight Booking Service provides a RESTful API to manage the end-to-end flight booking journey with the Amadeus Global Distribution System (GDS).
The API encompasses flight search, price quotation, order creation, order lookup, order updates, and order cancellation.

=== HTTP Status Codes
[cols="1,3"]
|===
| Status Code | Description

| `200 OK`
| Standard response for successful HTTP requests.

| `201 Created`
| The request has been fulfilled, resulting in the creation of a new flight order. The `Location` header contains the resource URI.

| `204 No Content`
| The request has been successfully fulfilled, such as after deleting or cancelling a flight order.

| `400 Bad Request`
| The server could not understand the request due to invalid syntax or parameters (RFC 7807 problem details).

| `502 Bad Gateway`
| Downstream Amadeus GDS service error or gateway failure.
|===
